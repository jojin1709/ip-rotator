How It Works

Simple 3-Step Process

Get started in under a minute

01

Install

Clone the repository and install dependencies

Terminal 
git clone https://github.com/jojin1709/ip-rotator.git
cd ip-rotator
npm install
02

Configure

Set up your preferred rotation mode

Terminal 
node rotator.js config --init
node rotator.js config --set mode=tor
03

Start Rotating

Launch the IP rotator and stay anonymous

Terminal 
node rotator.js start --mode tor --interval 60
Commands

Full Command Reference

17 powerful commands for complete IP and MAC management

status
Show current IP, MAC, and rotation status
node rotator.js status
start
Start IP/MAC rotation with options
node rotator.js start --mode tor --interval 60
stop
Stop all rotation activity
node rotator.js stop
rotate
Rotate IP immediately
node rotator.js rotate --mode proxy
quick --test
Quick connectivity and IP test
node rotator.js quick --test
mac --show
Show current MAC address
node rotator.js mac --show
mac --random
Randomize MAC address
node rotator.js mac --random
mac --set
Set specific MAC address
node rotator.js mac --set 00:11:22:33:44:55
mac --restore
Restore original MAC address
node rotator.js mac --restore
interfaces
List all network interfaces
node rotator.js interfaces
proxy --add
Add a proxy to the pool
node rotator.js proxy --add socks5://127.0.0.1:9050
proxy --file
Load proxies from file
node rotator.js proxy --file proxies.txt
proxy --test
Test all proxies in pool
node rotator.js proxy --test
speed
Test proxy speed and latency
node rotator.js speed --file proxies.txt
security --dns
Check for DNS leaks
node rotator.js security --dns
security --webrtc
Check for WebRTC IP leaks
node rotator.js security --webrtc
security --all
Run all security checks
node rotator.js security --all
check
Quick full security audit
node rotator.js check
export --history
Export rotation history
node rotator.js export --history -f csv
profiles --save
Save current config as profile
node rotator.js profiles --save bugbounty
profiles --load
Load a saved profile
node rotator.js profiles --load bugbounty
dashboard
Start web dashboard
node rotator.js dashboard --port 8080
